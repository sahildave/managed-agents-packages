# Thread watch

The agent instructions say what to do each run. This guide fixes what counts as a thread worth reporting, how to draft a reply and the report layout.

## Thread rules
- Look only in the communities the user named, over the last seven days. Read the thread's date on the page itself; if it shows no date or is older than seven days, leave it out.
- Put each thread in one section:
  - Asking for a tool like yours: someone describes one of the user's problem phrases and asks what to use.
  - Unhappy with a competitor: someone complains about a named competitor. Quote at most one short sentence.
  - Mentions of you: the product name or URL appears.
- Skip any thread URL that memory shows as already reported.
- For each community with nothing new, write one "Nothing new in <community>" line. Do not fill a section with weak matches.
- Name the communities you could not search, such as X or a forum behind a login, under "Not covered".

## Reply rules
- Draft replies for the five threads where a reply would help the poster most. Fewer is fine.
- Answer the question first, in the poster's terms. Mention the product only where it fits the question.
- Follow the user's reply rule. If it says nothing about disclosure, say plainly that the user makes the product.
- Follow the community's own self-promotion rules where you can read them, and link them.
- Never invent features, prices, users or results. Product facts come from the product page.
- The replies are drafts. Never post, vote or message.

## Report layout
```text
# Thread watch, week ending <yyyy-mm-dd>

## Asking for a tool like yours
- <thread title> (<link>, <yyyy-mm-dd>, <community>): <one line on what they need>

## Unhappy with a competitor
- <competitor>: <thread title> (<link>, <yyyy-mm-dd>): "<short quote>"

## Mentions of you
- <thread title> (<link>, <yyyy-mm-dd>): <one line>

## Drafted replies
### <thread title> (<link>)
<draft reply>

## Mentions per competitor
| Competitor | This week | Last week (<yyyy-mm-dd>) |
|---|---|---|

## Nothing new
- Nothing new in <community>

## Not covered
- <community>: <reason>
```

## Memory
- Save every reported thread URL with the date, so no thread is reported twice.
- Save this week's mention count per competitor. Show last week's count only when memory holds it; otherwise write "first week recorded".
- When the user says in a session which replies they posted, record that status in their words. Never mark a reply as posted yourself.
