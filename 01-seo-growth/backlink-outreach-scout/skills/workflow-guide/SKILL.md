# Backlink prospects

The agent instructions say what to do each run. This guide fixes what counts as a prospect, what you can claim and the report layout.

## What counts as a prospect
- A page that already links out to products, tools or articles like the user's: a resource page, a directory listing, a "best tools for" roundup, a newsletter issue or a community wiki.
- You fetched the page on this run and it is live. A page you only saw in search results is not a prospect yet.
- The page is on the user's topic. A general "web resources" page with hundreds of links is not a fit.
- Skip: pages that sell links or sponsored placements, private blog networks, link exchanges, comment and forum-signature links, the user's domains to skip, and anything memory lists as already suggested.

## Evidence rules
- You have no backlink or SEO tool. Never state domain authority, domain rating, traffic or spam scores. Say "authority unknown".
- Fit evidence comes from the page itself: name two or three comparable products it already links to.
- Contact route: copy it only if the page or the site's contact page shows it (an editor's name, a submit form, a public email). Never guess an email address or its pattern.
- If a page is blocked or needs a login, list it under "Could not check" instead of guessing.

## Pitch rules
- At most 90 words. Plain text, no flattery, no emoji.
- Name the exact page and the section where the link would go.
- Say in one sentence what the user's product does for that page's readers.
- Promise nothing the user did not offer: no link back, no payment.

## Report layout
```text
# Backlink prospects, <yyyy-mm-dd>

## 1. <site name>: <page title>
- Page: <URL> (fetched <yyyy-mm-dd>)
- Type: <resource page, directory, roundup, newsletter, wiki>
- Why it fits: links to <product A>, <product B>; <one line>
- Contact: <route shown on the site, or "not shown">
- Pitch draft (unsent):
  <pitch>

## Could not check
- <URL>: <blocked, login, gone>

## Already suggested before
- <URL>: <memory date>

## Next actions
1. <action>
```
Return five to ten prospects, best fit first. Save every suggested URL to memory with the date.
